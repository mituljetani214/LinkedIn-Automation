# Content Generation Instructions

Status: active
Last updated: 2026-07-27

## Goal

Generate LinkedIn content that reflects Mitul Jetani as an AI-native UX, product design, design systems, and human-centered automation leader.

## Inputs

Use these sources before drafting:

- `intake/master-career-intake.md`
- `intake/linkedin-profile-intake.md`
- `intake/writing-voice-intake.md`
- `career/profile.md`
- `career/projects.md`
- `career/skills.md`
- `linkedin/content-system/first-30-day-plan.md`
- `linkedin/content-system/content-approval-workflow.md`
- Latest research in `research/daily/`

## Content Types

- Text post
- Carousel outline
- Article draft
- Comment prompt
- Poll idea
- Image prompt
- Case-study teaser

## Required Metadata

Every content item should include:

- Title
- Status
- Date
- Category
- Source
- Target audience
- Content pillar
- Post body
- Suggested visual
- Image prompt
- Alt text
- Approval checklist
- Repo file path
- Notion page URL, once synced
- Cloudinary asset URL, once approved and uploaded
- Buffer post or idea ID, once created

## Voice Rules

- Keep the writing human, thoughtful, and direct.
- Avoid fake certainty, hype, and exaggerated AI claims.
- Use lived product and design experience.
- Make the post useful even if the reader never clicks anything.
- Keep AI framed as an amplifier of human judgment.

## Draft Lifecycle

1. Create in `linkedin/posts/review/`.
2. Sync to Notion.
3. Wait for approval.
4. Move to `linkedin/posts/approved/`.
5. Generate image or carousel package.
6. Upload approved visual to Cloudinary.
7. Create Buffer idea or scheduled post.
8. Move to `linkedin/posts/published/` after posting.
